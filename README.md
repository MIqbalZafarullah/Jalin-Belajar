# JALIN BELAJAR — Jejaring Aksi Literasi dan Numerasi Berbasis Data
> **Inovasi Teknologi Pendidikan Berbasis Data untuk Wilayah 3T**  
> *Implementasi Awal: Kabupaten Mukomuko, Provinsi Bengkulu*  
> **Functional Prototype untuk Kompetisi Inovasi EdTech Nasional FISION 2026**

---

## 🌟 Identitas & Tujuan Produk
**JALIN BELAJAR** mendemonstrasikan bagaimana data kondisi sekolah dan hasil asesmen diagnostik dapat digunakan untuk:
1. Memetakan disparitas infrastruktur dan capaian sekolah 3T (**JALIN-PETA**).
2. Menghitung penguasaan kompetensi dasar dan merekomendasikan materi remedial secara adaptif (**JALIN-TUNTAS**).
3. Mendampingi guru melalui bimbingan teknis, supervisi, dan kurasi praktik baik (**JALIN-GURU**).
4. Menjamin kegiatan belajar tetap berjalan lancar saat listrik dan sinyal padam melalui arsitektur luring (**JALIN-HUB**).

---

## 🚀 Fitur Utama & Keunggulan Prototipe
- **Simulasi 6 Peran Lengkap:** Super Admin, Dinas Pendidikan, Kepala Sekolah, Guru Koordinator, Guru Kelas, dan Siswa.
- **Role Switcher Instan:** Beralih akun hanya dengan 1 klik tanpa harus logout manual.
- **Offline-First Ready:** Menggunakan basis data peramban **Dexie.js IndexedDB** dan Service Worker Cache.
- **Penilaian & Rekomendasi Riil:** Skor dan analisis kompetensi dihitung secara langsung dari jawaban siswa (bukan angka statis).
- **Desain UI/UX EdTech Modern:** Menggunakan Tailwind CSS, palet warna Navy/Blue/Emerald, font Plus Jakarta Sans, dan ikon Lucide React.
- **Bebas Ketergantungan Server Berbayar:** Berjalan mulus 100% di peramban lokal.

---

## 💻 Cara Menjalankan

```bash
# 1. Pastikan dependensi telah terpasang
npm install

# 2. Jalankan server pengembangan lokal
npm run dev

# 3. Buka peramban di http://localhost:3000
```
